Lekcija 14 od 15 · ~30 minuta

Množina: jedna paleta, mnogo paleta

Kutije, ključevi, kolege, deca — ništa nije samo jedno. Naučite najčešće obrasce množine po rodu i nekoliko nepravilnih reči koje ćete čuti svaki dan.

🎯 Do kraja ove lekcije ćete moći da:

  • Napravite množinu imenica po rodu
  • Koristite jsou sa množinom (Tady jsou klíče.)
  • Zapamtite nepravilne: děti, lidé, přátelé
  • Opišete šta se nalazi u prostoriji
Korak 1 · Rečnik

Nove reči

Dodirnite ikonicu zvučnika da čujete svaku reč. Pokušajte da je ponovite naglas.

  • paleta → palety/PA-le-ta → PA-le-ti/paleta → palete
  • taška → tašky/TAŠ-ka → TAŠ-ki/torba → torbe
  • kniha → knihy/KNJI-ȟa → KNJI-ȟi/knjiga → knjige
  • krabice → krabice/KRA-bi-ce → KRA-bi-ce/kutija → kutije
  • byt → byty/bit → BI-ti/stan → stanovi
  • stůl → stoly/stūl → STO-li/sto → stolovi
  • klíč → klíče/klīč → KLĪ-če/ključ → ključevi
  • počítač → počítače/PO-čī-tač → PO-čī-ta-če/računar → računari
  • auto → auta/AU-to → AU-ta/auto → automobili
  • okno → okna/OK-no → OK-na/prozor → prozori
  • kolega → kolegové/KO-le-ga → KO-le-go-vē/kolega → kolege
  • student → studenti/STU-dent → STU-den-ći/student → studenti
  • dítě → děti/ĐĪ-će → ĐE-ći/dete → deca
  • člověk → lidé/ČLO-vjek → LI-dē/čovek → ljudi

💡 Savet

Kao i u srpskom, najčešće reči su nepravilne: dítě → děti (dete → deca), člověk → lidé (čovek → ljudi), přítel → přátelé (prijatelj → prijatelji). Njih učite napamet.

Korak 2 · Gramatika u fokusu

Obrasci množine po rodu

ženski na -a → -y paleta → palety · kniha → knihy
ženski na -e / -ě → bez promene krabice → krabice · kolegyně → kolegyně
muški neživi + -y (tvrdi) / -e (meki) byt → byty · klíč → klíče, počítač → počítače (č, š, ž, ř, j, c = meki)
muški živi + -i / -ové student → studenti · syn → synové · kolega → kolegové
srednji na -o → -a auto → auta · okno → okna · pivo → piva

📌 Dobro je znati

Ovaj oblik množine koristite i posle brojeva 2, 3, 4: dvě palety, tři klíče. Posle 5 i više dolazi poseban oblik: pět palet — vidi Brojevi i pravila brojanja. Više o množini: Osnovna množina.

Korak 5 · Pisanje

Napišite sami

Opišite šta se nalazi u vašoj kancelariji ili sobi. Koristite množinu: Tady jsou…, Mám…

Prikaži primer odgovora
V kanceláři jsou dva stoly a tři počítače. Na stole jsou knihy a klíče. Okna jsou velká. Moji kolegové jsou milí.

Sada prevedite ovu rečenicu na češki: "Imamo dve mačke i dvoje dece."

Prikaži primer odgovora
Máme dvě kočky a dvě děti.
